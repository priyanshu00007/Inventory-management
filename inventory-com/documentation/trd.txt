## **1. Executive Summary**

### **1.1 Technical Vision**
Build a **scalable, event-driven, cloud-native inventory management system** using microservices architecture (or modular monolith initially) that handles 10M+ products, processes 1M+ daily transactions, and maintains 99.9% availability with sub-200ms response times.

### **1.2 Architecture Principles**

| Principle | Description |
|-----------|-------------|
| **API First** | All functionality exposed via REST/GraphQL APIs |
| **Event-Driven** | Async processing for reports, notifications, integrations |
| **Stateless** | Any instance can handle any request |
| **Immutable Audit** | Transaction logs never modified, only appended |
| **Fail Fast** | Validate inputs early, return clear errors |
| **Observability** | Metrics, logs, traces for every operation |
| **Security by Design** | Authentication, authorization, encryption at all layers |

```yaml
  RDS PostgreSQL 15:

    - Read Replica 2: db.r5.large (Analytics)

Cache:
  ElastiCache Redis:
    - Primary: cache.t3.medium (3.22GB)
    - Replica: cache.t3.medium (failover)
    - Configuration: Cluster mode disabled

Queue:
  Amazon MQ / SQS:
    - Standard Queue: High throughput
    - FIFO Queue: Order-critical operations
  
Storage:
  S3 Buckets:
    - static-assets: CDN + CloudFront
    - product-images: With versioning
    - backups: Encrypted, lifecycle rules
    - logs: Centralized logging

CDN:
  CloudFront:
    - TTL: 86400 seconds (cache static)
    - Price class: Use only North America/Europe
```

### **4.3 Core Service Implementation**

**`src/services/stock.service.ts`** (Complete Business Logic)

```typescript
import { PrismaClient, TransactionType, StockStatus } from '@prisma/client';
import { DatabaseError } from '../utils/ApiError';
import { logger } from '../config/logger';
import { EventEmitter } from 'events';
import { publishToQueue } from '../queues/producer';

const prisma = new PrismaClient();
const eventEmitter = new EventEmitter();

interface AddStockInput {
  productId: string;
  quantity: number;
  warehouseId: string;
  locationId?: string;
  batchNumber?: string;
  expiryDate?: Date;
  reference?: string;
  notes?: string;
  userId: string;
  ipAddress?: string;
}

interface RemoveStockInput {
  productId: string;
  quantity: number;
  warehouseId: string;
  type: TransactionType;
  reference?: string;
  notes?: string;
  userId: string;
  ipAddress?: string;
}

export class StockService {
  
  /**
   * Add stock to inventory with transaction logging
   */
  async addStock(input: AddStockInput) {
    const {
      productId,
      quantity,
      warehouseId,
      locationId,
      batchNumber,
      expiryDate,
      reference,
      notes,
      userId,
      ipAddress
    } = input;

    if (quantity <= 0) {
      throw new Error('Quantity must be greater than 0');
    }

    // Use database transaction for consistency
    const result = await prisma.$transaction(async (tx) => {
      // 1. Get or create stock record
      let stock = await tx.stock.findUnique({
        where: {
          productId_warehouseId_variantId_batchNumber: {
            productId,
            warehouseId,
            variantId: '', // No variant for now
            batchNumber: batchNumber || ''
          }
        }
      });

      const previousQty = stock?.quantity || 0;
      const newQty = previousQty + quantity;

      if (stock) {
        // Update existing stock
        stock = await tx.stock.update({
          where: { id: stock.id },
          data: {
            quantity: newQty,
            availableQty: newQty - (stock.reservedQty || 0),
            updatedBy: userId,
            ...(locationId && { locationId }),
            ...(batchNumber && { batchNumber }),
            ...(expiryDate && { expiryDate })
          }
        });
      } else {
        // Create new stock record
        stock = await tx.stock.create({
          data: {
            productId,
            warehouseId,
            locationId,
            quantity: newQty,
            availableQty: newQty,
            updatedBy: userId,
            batchNumber,
            expiryDate,
            receivedDate: new Date()
          }
        });
      }

      // 2. Create transaction log (immutable)
      const transaction = await tx.transaction.create({
        data: {
          type: TransactionType.PURCHASE,
          quantity,
          previousQty,
          newQty,
          reference,
          notes,
          productId,
          warehouseId,
          locationId,
          batchNumber,
          userId,
          ipAddress,
          metadata: {
            timestamp: new Date().toISOString(),
            userAgent: 'API'
          }
        }
      });

      // 3. Update product last updated timestamp
      await tx.product.update({
        where: { id: productId },
        data: { updatedAt: new Date() }
      });

      // 4. Check low stock and trigger alert
      const product = await tx.product.findUnique({
        where: { id: productId },
        select: { reorderLevel: true, name: true, sku: true }
      });

      if (product && newQty <= product.reorderLevel) {
        await this.triggerLowStockAlert({
          productId,
          productName: product.name,
          sku: product.sku,
          currentStock: newQty,
          reorderLevel: product.reorderLevel,
          warehouseId
        });
      }

      return { stock, transaction };
    });

    // 5. Emit event for real-time updates
    eventEmitter.emit('stock.updated', {
      productId,
      warehouseId,
      oldQuantity: result.stock.quantity - quantity,
      newQuantity: result.stock.quantity,
      type: 'ADD'
    });

    // 6. Publish to queue for async processing (webhooks, notifications)
    await publishToQueue('stock-events', {
      event: 'stock.added',
      data: {
        productId,
        quantity,
        warehouseId,
        transactionId: result.transaction.id,
        timestamp: new Date()
      }
    });

    logger.info(`Stock added: Product ${productId}, Quantity ${quantity}, User ${userId}`);
    
    return {
      transactionId: result.transaction.id,
      previousQuantity: result.transaction.previousQty,
      newQuantity: result.transaction.newQty,
      currentStock: result.stock.quantity
    };
  }

  /**
   * Remove stock from inventory (sales, damages, adjustments)
   */
  async removeStock(input: RemoveStockInput) {
    const {
      productId,
      quantity,
      warehouseId,
      type,
      reference,
      notes,
      userId,
      ipAddress
    } = input;

    if (quantity <= 0) {
      throw new Error('Quantity must be greater than 0');
    }

    const result = await prisma.$transaction(async (tx) => {
      // 1. Get current stock with lock (FOR UPDATE)
      const stock = await tx.$queryRaw`
        SELECT * FROM stocks 
        WHERE product_id = ${productId} 
        AND warehouse_id = ${warehouseId}
        FOR UPDATE
      `;

      const currentStock = await tx.stock.findUnique({
        where: {
          productId_warehouseId_variantId_batchNumber: {
            productId,
            warehouseId,
            variantId: '',
            batchNumber: ''
          }
        }
      });

      if (!currentStock) {
        throw new Error('Product not found in warehouse');
      }

      if (currentStock.quantity < quantity) {
        throw new Error(`Insufficient stock. Available: ${currentStock.quantity}, Requested: ${quantity}`);
      }

      const previousQty = currentStock.quantity;
      const newQty = previousQty - quantity;

      // 2. Update stock
      const updatedStock = await tx.stock.update({
        where: { id: currentStock.id },
        data: {
          quantity: newQty,
          availableQty: newQty - (currentStock.reservedQty || 0),
          updatedBy: userId
        }
      });

      // 3. Create transaction log
      const transaction = await tx.transaction.create({
        data: {
          type,
          quantity: -quantity, // Negative for removal
          previousQty,
          newQty,
          reference,
          notes,
          productId,
          warehouseId,
          userId,
          ipAddress,
          metadata: {
            timestamp: new Date().toISOString(),
            removalType: type
          }
        }
      });

      return { stock: updatedStock, transaction };
    });

    // Emit events
    eventEmitter.emit('stock.updated', {
      productId,
      warehouseId,
      oldQuantity: result.stock.quantity + quantity,
      newQuantity: result.stock.quantity,
      type: 'REMOVE'
    });

    logger.info(`Stock removed: Product ${productId}, Quantity ${quantity}, Type ${type}, User ${userId}`);
    
    return {
      transactionId: result.transaction.id,
      previousQuantity: result.transaction.previousQty,
      newQuantity: result.transaction.newQty,
      currentStock: result.stock.quantity
    };
  }

  /**
   * Transfer stock between warehouses
   */
  async transferStock(input: {
    productId: string;
    quantity: number;
    fromWarehouseId: string;
    toWarehouseId: string;
    userId: string;
    notes?: string;
  }) {
    const { productId, quantity, fromWarehouseId, toWarehouseId, userId, notes } = input;

    if (fromWarehouseId === toWarehouseId) {
      throw new Error('Source and destination warehouses cannot be the same');
    }

    const result = await prisma.$transaction(async (tx) => {
      // 1. Remove from source warehouse
      const sourceStock = await tx.stock.findUnique({
        where: {
          productId_warehouseId_variantId_batchNumber: {
            productId,
            warehouseId: fromWarehouseId,
            variantId: '',
            batchNumber: ''
          }
        }
      });

      if (!sourceStock || sourceStock.quantity < quantity) {
        throw new Error(`Insufficient stock in source warehouse`);
      }

      // Remove from source
      await tx.stock.update({
        where: { id: sourceStock.id },
        data: {
          quantity: sourceStock.quantity - quantity,
          availableQty: sourceStock.quantity - quantity - (sourceStock.reservedQty || 0),
          updatedBy: userId
        }
      });

      // Create transfer-out transaction
      await tx.transaction.create({
        data: {
          type: TransactionType.TRANSFER_OUT,
          quantity: -quantity,
          previousQty: sourceStock.quantity,
          newQty: sourceStock.quantity - quantity,
          reference: `TRANSFER_${Date.now()}`,
          notes: `Transfer to ${toWarehouseId}. ${notes || ''}`,
          productId,
          warehouseId: fromWarehouseId,
          userId
        }
      });

      // 2. Add to destination warehouse
      let destStock = await tx.stock.findUnique({
        where: {
          productId_warehouseId_variantId_batchNumber: {
            productId,
            warehouseId: toWarehouseId,
            variantId: '',
            batchNumber: ''
          }
        }
      });

      const destPreviousQty = destStock?.quantity || 0;
      const destNewQty = destPreviousQty + quantity;

      if (destStock) {
        await tx.stock.update({
          where: { id: destStock.id },
          data: {
            quantity: destNewQty,
            availableQty: destNewQty - (destStock.reservedQty || 0),
            updatedBy: userId
          }
        });
      } else {
        await tx.stock.create({
          data: {
            productId,
            warehouseId: toWarehouseId,
            quantity: destNewQty,
            availableQty: destNewQty,
            updatedBy: userId
          }
        });
      }

      // Create transfer-in transaction
      await tx.transaction.create({
        data: {
          type: TransactionType.TRANSFER_IN,
          quantity,
          previousQty: destPreviousQty,
          newQty: destNewQty,
          reference: `TRANSFER_${Date.now()}`,
          notes: `Transfer from ${fromWarehouseId}. ${notes || ''}`,
          productId,
          warehouseId: toWarehouseId,
          userId
        }
      });

      return { success: true };
    });

    logger.info(`Stock transferred: Product ${productId}, Quantity ${quantity}, From ${fromWarehouseId} To ${toWarehouseId}`);
    
    return result;
  }

  /**
   * Get current stock level with caching
   */
  async getStockLevel(productId: string, warehouseId?: string) {
    // Try cache first
    const cacheKey = `stock:${productId}:${warehouseId || 'all'}`;
    // const cached = await redisClient.get(cacheKey);
    // if (cached) return JSON.parse(cached);

    const where: any = { productId };
    if (warehouseId) {
      where.warehouseId = warehouseId;
    }

    const stocks = await prisma.stock.findMany({
      where,
      include: {
        warehouse: {
          select: { name: true, code: true }
        },
        location: true
      }
    });

    const result = {
      productId,
      totalQuantity: stocks.reduce((sum, s) => sum + s.quantity, 0),
      totalReserved: stocks.reduce((sum, s) => sum + (s.reservedQty || 0), 0),
      totalAvailable: stocks.reduce((sum, s) => sum + (s.availableQty || 0), 0),
      warehouses: stocks.map(s => ({
        warehouseId: s.warehouseId,
        warehouseName: s.warehouse.name,
        quantity: s.quantity,
        reserved: s.reservedQty,
        available: s.availableQty,
        location: s.location?.code
      }))
    };

    // Cache for 5 minutes
    // await redisClient.setex(cacheKey, 300, JSON.stringify(result));

    return result;
  }

  /**
   * Trigger low stock alert
   */
  private async triggerLowStockAlert(data: any) {
    await publishToQueue('alerts', {
      type: 'LOW_STOCK',
      priority: 'HIGH',
      data,
      timestamp: new Date()
    });
  }
}
```

**`src/middlewares/cache.middleware.ts`**

```typescript
import { Request, Response, NextFunction } from 'express';
import Redis from 'ioredis';
import { config } from '../config/env';

const redisClient = new Redis({
  host: config.redis.host,
  port: config.redis.port
});

export const cacheMiddleware = (duration: number = 300) => {
  return async (req: Request, res: Response, next: NextFunction) => {
    // Only cache GET requests
    if (req.method !== 'GET') {
      return next();
    }

    const key = `cache:${req.originalUrl}`;
    
    try {
      const cachedData = await redisClient.get(key);
      
      if (cachedData) {
        const data = JSON.parse(cachedData);
        res.setHeader('X-Cache', 'HIT');
        return res.json(data);
      }
      
      // Store original send function
      const originalSend = res.json;
      
      // Override send function
      res.json = function(body) {
        // Cache the response
        if (res.statusCode === 200) {
          redisClient.setex(key, duration, JSON.stringify(body));
          res.setHeader('X-Cache', 'MISS');
        }
        
        return originalSend.call(this, body);
      };
      
      next();
    } catch (error) {
      // Redis error - continue without cache
      console.error('Cache error:', error);
      next();
    }
  };
};

// Invalidate cache helper
export const invalidateCache = async (pattern: string) => {
  const keys = await redisClient.keys(`cache:${pattern}`);
  if (keys.length > 0) {
    await redisClient.del(...keys);
  }
};
```

```typescript
  await generateReport(reportId, type, parameters, userId);
}, { connection });

// Producer function
export const publishToQueue = async (queueName: string, data: any, delay?: number) => {
  let queue: Queue;
  
  switch(queueName) {
    case 'email':
      queue = emailQueue;
      break;
    case 'webhook':
      queue = webhookQueue;
      break;
    case 'report':
      queue = reportQueue;
      break;
    case 'alerts':
      queue = stockAlertQueue;
      break;
    default:
      throw new Error(`Unknown queue: ${queueName}`);

  await queue.add(queueName, data, {
    delay,
    attempts: 3,
    backoff: {
      type: 'exponential',
      delay: 1000
    },
    removeOnComplete: true,
    removeOnFail: false
  });
```

### **5.2 Encryption Service**

```typescript
import crypto from 'crypto';

const ALGORITHM = 'aes-256-gcm';
const IV_LENGTH = 16;
const SALT_LENGTH = 64;
const TAG_LENGTH = 16;

export class EncryptionService {
  private static encryptionKey: Buffer;
  
  static initialize(masterKey: string) {
    this.encryptionKey = crypto.scryptSync(masterKey, 'salt', 32);
  }
  
  static encrypt(text: string): string {
    const iv = crypto.randomBytes(IV_LENGTH);
    const cipher = crypto.createCipheriv(ALGORITHM, this.encryptionKey, iv);
    
    const encrypted = Buffer.concat([
      cipher.update(text, 'utf8'),
      cipher.final()
    ]);
    
    const tag = cipher.getAuthTag();
    
    // Combine: iv + tag + encrypted data
    const result = Buffer.concat([iv, tag, encrypted]);
    return result.toString('base64');
  }
  
  static decrypt(encryptedText: string): string {
    const buffer = Buffer.from(encryptedText, 'base64');
    
    const iv = buffer.subarray(0, IV_LENGTH);
    const tag = buffer.subarray(IV_LENGTH, IV_LENGTH + TAG_LENGTH);
    const encrypted = buffer.subarray(IV_LENGTH + TAG_LENGTH);
    
    const decipher = crypto.createDecipheriv(ALGORITHM, this.encryptionKey, iv);
    decipher.setAuthTag(tag);
    
    const decrypted = Buffer.concat([
      decipher.update(encrypted),
      decipher.final()
    ]);
    
    return decrypted.toString('utf8');
  }
}
```

```typescript
async function getProductsCursor(cursor?: string, limit: number = 20) {
  return await prisma.product.findMany({
    take: limit + 1,
    cursor: cursor ? { id: cursor } : undefined,
    skip: cursor ? 1 : 0,
    orderBy: { id: 'asc' },
    where: { isActive: true },
    select: {
      id: true,
      sku: true,
      name: true,
      unitPrice: true,
      // Only select needed fields
    }
  });
}

// Batch loading with DataLoader
import DataLoader from 'dataloader';

const batchProducts = async (ids: readonly string[]) => {
  const products = await prisma.product.findMany({
    where: { id: { in: [...ids] } }
  });
  
  return ids.map(id => products.find(p => p.id === id));
};

export const productLoader = new DataLoader(batchProducts);
```

```typescript
export const metricsMiddleware = (req: Request, res: Response, next: NextFunction) => {
  const start = Date.now();
  
  res.on('finish', () => {
    const duration = (Date.now() - start) / 1000;
    httpRequestDuration.labels(req.method, req.route?.path || req.path, res.statusCode.toString())

  });
  
  next();
};
```

## **10. Disaster Recovery Plan**

### **10.1 Backup Strategy**

```bash
#!/bin/bash
# backup.sh - Automated database backup

BACKUP_DIR="/backups/postgres"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=30

# Create backup
pg_dump -h $DB_HOST -U $DB_USER -d $DB_NAME \
  | gzip > $BACKUP_DIR/backup_$DATE.sql.gz

# Upload to S3
aws s3 cp $BACKUP_DIR/backup_$DATE.sql.gz \
  s3://inventory-backups/production/

# Delete old backups
find $BACKUP_DIR -type f -mtime +$RETENTION_DAYS -delete

# Verify backup
gunzip -t $BACKUP_DIR/backup_$DATE.sql.gz
if [ $? -eq 0 ]; then
  echo "Backup verified successfully"
else
  echo "Backup verification failed"
  exit 1
fi
```

### **10.2 Recovery Procedure**

```sql
-- Step 1: Restore from latest backup
pg_restore -h $DB_HOST -U $DB_USER -d $DB_NAME \
  --clean --if-exists \
  latest_backup.dump

-- Step 2: Verify data integrity
SELECT COUNT(*) FROM products;
SELECT COUNT(*) FROM transactions;

-- Step 3: Check for any missing sequences
SELECT setval('products_id_seq', (SELECT MAX(id) FROM products));

-- Step 4: Rebuild indexes if needed
REINDEX DATABASE inventory_db;

-- Step 5: Refresh materialized views
REFRESH MATERIALIZED VIEW stock_summary;
```

## **11. Technical Risks & Mitigations**

| Risk | Probability | Impact | Mitigation Strategy |
|------|------------|--------|---------------------|
| Database deadlocks | Medium | High | Implement retry logic, use advisory locks, optimize transactions |
| Memory leaks | Low | High | Heap profiling, automatic restart on threshold, memory limits |
| Redis failure | Low | Medium | Circuit breaker pattern, fallback to direct DB queries |
| API throttling bypass | Low | High | Distributed rate limiting with Redis, API key rotation |
| Data corruption | Very Low | Critical | ACID transactions, WAL archiving, point-in-time recovery |
| Third-party API outages | Medium | Medium | Circuit breakers, retry with exponential backoff, fallback data |
